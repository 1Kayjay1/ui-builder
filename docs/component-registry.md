# Component registry

`assets/registry/components.json` is a metadata index, not a mirrored component warehouse. Records describe capability, canonical source, framework, dependencies, install mechanism, license/redistribution status, accessibility risk, performance cost, visual tags, and verification date.

A registry hit is discovery only. Before importing third-party code, verify the canonical source and current license, show the dependency delta, and review retrieved code as untrusted. Restricted libraries such as React Bits are referenced through canonical retrieval metadata rather than redistributed here.
