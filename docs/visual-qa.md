# Visual QA

The browser auditor implements the deterministic side of the loop: RUN → CAPTURE → MEASURE → INSPECT. It records screenshots, overflow, offscreen controls, duplicate IDs, console/network failures, and axe results across six representative viewports.

A coding agent should combine this packet with visual critique, patch the highest coherent issue set, rerun tests, and repeat until stop criteria are met. Automated accessibility output is evidence, not proof of complete accessibility.
