# Typography

Choose roles before fonts: display, body, UI, data, mono when semantics benefit. Evaluate readability at actual sizes, metrics/x-height, glyph coverage, numeric forms, variable axes, optical sizing, licensing, file weight, fallbacks, and platform rendering. One family can serve all roles. Prefer semantic fluid sizes over a rigid universal modular scale. For data-heavy interfaces use tabular numerals where comparisons matter and design for long/localized values. Preload only critical WOFF2 assets.
