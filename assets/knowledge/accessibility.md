# Accessibility

Default target: WCAG 2.2 AA. Design for semantic HTML, keyboard operation, visible/unobscured focus, labels/names, correct ARIA, contrast, 24×24 CSS px target minimum or applicable exception/spacing, non-drag alternatives, reduced motion, zoom/reflow, accessible authentication, and redundant-entry requirements. Automated axe checks find many defects but cannot prove reading order, announcement quality, cognitive clarity, or complete interaction correctness.
