# Polish checklist

Visual: alignment/baselines, spacing, radius/border/shadow consistency, first-glance hierarchy, line length/wrap, truncation, icon alignment, empty/error/loading, selection, cursor, scrollbars. Interaction: hover/pressed/focus/disabled, keyboard traversal, focus restoration, pointer cancellation, touch, copy/save/upload feedback, destructive confirmation, optimistic rollback. Browser/input: autofill, placeholder, caret, native controls, zoom, safe areas, overscroll, reduced motion. Data: locale-aware dates/numbers/currency/negatives and no fake metrics/charts.
