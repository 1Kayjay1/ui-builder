# Licensing and copyright

Every imported or referenced resource needs provenance. References are inspiration/analysis; store links and derived observations unless rights allow more. Verify component license and source, preserve notices, record restrictions, and reject unknown/restricted redistribution under project policy. Fonts, icons, 3D assets, shaders, and code can carry separate licenses. React Bits is metadata/link integration only because the researched license restricts redistribution of the component collection. Never mirror the collection into this pack.
