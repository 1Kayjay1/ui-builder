# Reference research

Search first, rights-aware, synthesis-oriented. Prefer official APIs or supported search, canonical links, permitted browser access, then user-provided screenshots. Do not make automated scraping of Pinterest, Dribbble, or design galleries a core dependency. Store URL, source, captured date, useful-for dimensions, observations, do-not-copy notes, and rights mode. Extract principles rather than pixels. Group a reference board by contribution such as typography, density, navigation, or motion.
