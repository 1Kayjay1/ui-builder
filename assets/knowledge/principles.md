# Design engineering principles

Quality, not one aesthetic, is the invariant. Understand the project before changing it. Plan user job → content priority → interaction frequency → regions → alignment/grid → density → responsive transformations → components → decoration. Prefer the smallest coherent change set. A build passing is necessary, never sufficient.

Keep judgment in skills and deterministic work in tools. Models decide why a direction fits; tools measure layout, contrast, files, runtime failures, and registry metadata. Preserve established visual identity unless the task is explicitly a redesign.
