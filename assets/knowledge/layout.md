# Layout and composition

Prefer intrinsic sizing, Grid for 2D composition, Flexbox for 1D distribution, `minmax()`, `min()`, `max()`, `clamp()`, logical properties, and predictable overflow. Avoid fixed heights around variable content, viewport assumptions inside reusable components, nested scroll regions without a real interaction need, and absolute-positioned application layouts. Every surface must answer what is primary, secondary, grouped, hidden-until-needed, persistent, and collapsible.
