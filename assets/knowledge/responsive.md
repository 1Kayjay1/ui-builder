# Responsive design

Responsive design is transformation, not desktop stacking. For each region choose preserve, reflow, compress, collapse, replace, move, hide-with-access-path, progressively-disclose, or change-interaction. Use content failure points rather than fetishizing device breakpoints; use representative devices for QA only. Check keyboard opening, safe areas, sticky obstruction, landscape, long translations, text zoom, coarse pointer, and touch target comfort.
