# Visual QA

Mandatory loop: IMPLEMENT → RUN → CAPTURE → MEASURE → INSPECT → CRITIQUE → PATCH → REPEAT. Default viewports: 360×800, 390×844, 768×1024, 1280×800, 1440×900, 1920×1080. Capture screenshots plus overflow, console/network errors, accessibility results, important state evidence, and key layout measurements. Stop with no severity-1 defects, no unexpected horizontal overflow, required states/viewports passing, and no high-impact critique remaining or when the iteration cap is reached. Hard measurable failures outrank aesthetic preference.
