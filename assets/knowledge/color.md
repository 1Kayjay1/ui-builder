# Color

Use role-based color, not decorative swatches. OKLCH is a useful authoring space when supported: derive surface/text/border ladders, interaction states, gamut-map, validate contrast, and repair failures. Do not derive success/warning/error by arbitrary hue rotation from a brand seed. Charts need perceptual distinction, color-vision robustness, surface contrast, and non-color encodings when needed. Contrast is measured, not eyeballed.
