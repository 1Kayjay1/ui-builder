# Design Match

Activate when the user supplies screenshots, sites, Figma references, moodboards, or named visual targets.

1. Analyze each reference by hierarchy, rhythm, density, grouping, alignment, typography, color roles, surfaces, navigation, motion, feedback, distinctiveness, and restraint.
2. For each useful reference, record OBSERVATION → PRINCIPLE → TRANSFERABILITY → DO NOT COPY.
3. Build a direction from several transferable principles. Do not let one source dominate the composition.
4. Preserve the project's real requirements, content, brand, and interaction model.
5. Do not reproduce logos, illustrations, branded type, or distinctive page composition unless the user owns/provides those assets and requests reuse.
6. Implement with project tokens and real state.
7. Compare rendered output at representative viewports, then repair measurable issues before visual tuning.

Load: `visual-taste.md`, `reference-research.md`, `typography.md`, `color.md`, `layout.md`, `motion.md`, `licensing.md`, `visual-qa.md`.

Completion: the result captures transferable design principles while remaining an original project-specific composition.
